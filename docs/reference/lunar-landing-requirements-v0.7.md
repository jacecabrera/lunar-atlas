2. 输入与任务时间

   | 字段 | 含义与单位 |
   | --- | --- |
   | Landing Time | 接触月面时刻，UTC；落地立即开始任务 |
   | Duration of journey | 月面太阳能任务持续时间，单位 Earth day（24 小时）；不是赴月飞行时间 |
   | Launch site Earth | 手动输入地球发射地点经纬度 |
   | More settings | 展开设备预设、有效估时速度、效率、初始储能、评分权重等 |

   - 月面分析窗口为 [着陆时刻, 着陆时刻 + 月面任务天数]；不设置等待日出或部署等待时间。
   - 初始储能用于覆盖任务开始后的黑暗；达到最低保留线而仍需净放电时不合格。
   - Solar efficiency 与用户说的 recharge efficiency 是同一光伏转换效率，只保留一个输入。
   - Energy use efficiency 对应 polar energy use efficiency；本版具体定义为公共电源母线至设备电输入端的供电效率。
   - Initial stored energy 对应 initial polar energy restored，单位 Wh，定义在电池内部储能端。
   - 储能充/放电效率是不同物理量，若展示必须清楚命名，不能重复使用光伏效率。
   - 月面任务时长不得拿来反推发射日期。
   - 用户填写前不伪造 Landing Time、任务天数或发射地点；数值必须有限，时长/速度大于零，经纬度在合法范围。

3. 飞行估时与航线

   - 用户定义 velocity in vacuum 为平均速度。本版界面建议写 Effective transit speed，默认 1.5 km/s，用作简化距离/时间估算。
   - 数值依据约 384,400 km / 3 天 ≈ 1.48 km/s 后取整，是等效估时参数；没有证据称它是统计上“最常见”或实测轨迹平均速度。
   - 估时使用同一地心惯性参考系中地球发射位置与月球目的点的端点距离 / 有效速度；发射位置取估计发射时刻、月面点取着陆时刻，迭代更新发射时刻。坐标转换和收敛须在实现时核验。
   - 发射时间 = Landing Time − Estimated transit time。该模型不求轨道、停泊、燃料、降落动力学或发射窗口可行性。
   - 发射地点影响估时和示意线起点；不凭这条简化关系声称某发射场可发射，也不让它制造月面光照/地形差异。
   - 渲染曲线明确标为 Illustrative trajectory；不把为了好看而弯曲的线长混入物理结论。
   - 每个推荐点对应一条鲜明航线；有效自定义点追加自己的航线，不替换、不填补推荐条数。最多按 3+9 显示 12 条。

4. 候选库、筛选与排序

   - 搜索范围是指定候选库，数据由助手按用户提供的资源方向整理。
   - 初版 JSON 收录 12 个已核对坐标的历史参照点：Apollo 11/12/14/15/16/17、Surveyor 7、Luna 16、Chang'e 3/4/5、Chandrayaan-3。
   - 它是初始历史点子集，不是 QuickMap 全图层导出，不是全球所有候选点，也不是“12 个已验证安全着陆点”。坐标来源为 NASA/NSSDCA，地形后续从 QuickMap/Moon Trek 对应数值产品核验。
   - 坐标采用来源的 DE421 mean Earth/polar axis 框架、东经为正；保留来源小数位，不虚构定位误差，转换到现有月固框架须核验。
   - 历史记录对应的可能是下降级/着陆器硬件位置，设有已知硬件提示。推荐历史点本身，不自动平移到附近；有障碍重叠时不能因为历史身份放行。
   - 候选资料登记与任务合格性分开。当前地形/能源/通信均未计算，landingAllowed=null、eligibleForRecommendation=false。
   - 先做地形、供能、对地通信必要条件及数据完整性检查，再加权排序；不合格或未评估者不进入推荐。
   - 默认 S = 100 × (0.50 L + 0.30 C + 0.20 T)；权重是用户确认项，可在 More settings 调整、归一化，全零无效。
   - L = 日照时间 / 任务时长；C = 地球几何可见时间 / 任务时长。
   - T 的初版项目评分定义为 clamp(1 − 足迹内已评估最大坡度 / 5°, 0, 1)。它是便于解释的项目排序规则；危险障碍及数据不足由硬过滤处理，不靠分数抵消。
   - 依用户授权选择：硬条件通过后不再添加无依据的 60/70 分最低分线。低分只影响排序；不是着陆成功概率。
   - 先分数降序，按 0.01 分精度视为同分；同分历史优先；同级再优先选择彼此分散的点，最后以稳定 ID 决定顺序。这些精度/确定性细节是项目算法选择。
   - 推荐 1–3 个，不凑数。用户接受“当前条件和搜索范围内没有合格推荐点”。
   - 遵照此前要求：无合格推荐时禁用自定义确认，解释原因。数据缺失、服务失败与物理不满足必须分别说明。

5. 参考设备、能源及最低条件

   - 采用 ILN-inspired solar lander 教学配置，以 NASA ILN Case 1 太阳能＋电池概念设计为资料依据；不是已飞设备的完整复制。
   - 来源值：光伏效率 30%；两块 54×54 cm 固定东/西向面板；总面积 0.5832 m²；阵列标称 100 W；约 23 W 夜间基础电负载、5 W 通信电负载。
   - 项目补充值：面板倾角 90°、连续基础负载 23 W、地球可见时附加 5 W、用能效率 90%、储能容量及初始电量 12,000 Wh、20% 保留线 2,400 Wh、电池充/放电效率各 95%、母线充/放电功率上限各 100 W。详见配置来源说明。
   - 把 ILN 标称 100 W 用作本模型光伏控制器输出上限是项目选择；不能伪称其实际硬件额定上限已查明。
   - 23/5 W 定义在设备电输入端，除以 90% 只计算额外的母线配送损失；不把这些电输入功率再次当机械有用功率。
   - 全任务检查储能和瞬时供电；不能用累计日照或“太阳已出现”替代能量时序。
   - E ≥ E_min；净负载不能超过可用放电功率；触及保留线后不能继续净放电。日后再充回来不抵消先前失败。
   - 模型尚未验证热控、温度相关电池性能、寿命、额外尘埃/老化损失。结果只能叫当前模型下条件通过。
   - 地形参考配置：坡度达到/超过 5°、已知障碍达到/超过 0.3 m 时排除；源自 ALHAT 危险检测尺度，不是所有着陆器通用安全认证。
   - 局部地形分析足迹默认直径 3 m，明确为项目设置，不是已查实的 ILN 几何尺寸；不声称覆盖实际落点散布椭圆。
   - 数据尺度或误差不足以判断上述条件时标未评估，不推荐、不允许确认、不进入完整比较。不能以 5 m DEM 声称排除了 0.3 m 障碍。
   - 已知遗留硬件、陡崖、坑缘等按足迹重叠的实际坡度/障碍处理，不把整座陨坑一律禁用。
   - 通信几何默认使用地球圆盘中心，高于地形地平线且超过可调最低仰角（默认 0°）。这是项目几何定义。
   - 最低要求为任务内存在正时长、且有供电的直接对地可见机会；不提供中继。只要有电不代表地球不被遮挡，也不代表无线电链路已验证。
   - 通信运行默认覆盖所有几何可见时段并计入能源；不另行编造数据率/最低回传量。

6. 主侧栏与月面选择

   - Sidebar 输入三个主要字段并提供 More settings；输出推荐点主要显示经纬度。
   - 推荐列表后有自定义经纬度输入，最多 9 个自定义点，可更名/删除。
   - 可点击月面填入输入框；只要求月球悬浮坐标提示，不要求地球/太阳提示。
   - 不可用点悬浮坐标红色；点击仍可填入，但输入框标红、原因可读、确认按钮不可用。
   - 未评估须显示真实原因，不能标成已证实危险或安全。
   - Learn more 位于底部，在新浏览器标签页打开；不再要求先 Ctrl 多选才能进入，详情包含所有有效推荐/自定义点。

7. Learn more、比较与数据保留

   | 核心组 | 输出 |
   | --- | --- |
   | 日照 | 累计日照时长、日照比例 |
   | 连续黑暗 | 最长连续无日照时长 |
   | 对地可见 | 窗口时间条、占比、最长可见窗口及最长不可见间隔 |
   | 同时可见 | 太阳与地球同时可见比例 |
   | 太阳高度 | 可见期间平均值、峰值、可展开曲线 |

   - Sunlight duration 按太阳圆盘任意部分越过当地地形地平线计算；供能需进一步考虑实际可见圆盘比例和面板入射角，不能见到一点太阳就当满功率。
   - 详情中点击数字显示计算公式、变量含义与数据来源。来源/分辨率/模型限制必备；尚未测得的 Horizons 误差不填数字。
   - Relative solar power 暂缓作为进阶展示；不影响内部必须进行能源判定。
   - Time to next sunset / Earthset 是从当前选定时刻到下一次太阳/地球由可见转为不可见的剩余时间；若搜索窗口内无事件，显示未找到及搜索范围，不能显示为零。
   - 比较只是并排显示不同点数据，由用户自己判断；不强加基准或 Change from baseline。
   - 顶部有点位列表，可切换/关闭某点展示；支持多点同时显示。按有效推荐3个＋自定义9个，可能达到12项；网格/滚动布局须保持可读，不硬塞进一屏。
   - 已打开详情页保存打开时的任务数据快照。主页面修改输入、删除点或 Clear 不关闭这些标签页，也不清空其中数据；详情自身关闭点只改变该页展示。
   - “删除不保留”本版依据用户最新表述落实为主页面任务数据被清除；不把它写成广播清空已有详情页。
   - 项目交互选择：修改主要输入/设备设置后主页旧结果标记失效，重新确认计算后更新；此前已打开详情快照仍保留。

8. 时钟、时间轴与 Clear：用户已最终确认

   - UTC 显示；左上角时间、开始/暂停、倍率；页面打开默认自动播放。
   - 默认 1× = 与现实时间同速；其余 1.25、1.5、2、3、5×。
   - 初始范围是加载时系统现在 ±10 个日历年，游标位于现在。边界可自定义；模型支持年限须核验，不能造一个天文精度保证。
   - 计算时暂停并跳至 Landing Time，锁定时间轴；普通 Reset 不得绕过。Clear/Reset input 才解锁。
   - Clear 需二次确认；取消不改动。确认时清空主页面输入、结果、自定义列表及航线，重置高级设置。
   - Clear 后回到确认那一刻的系统时间、解锁并自动播放。本版将播放倍率恢复默认 1×，作为重置行为细节。
   - 用户最终确定的范围处理：

     | 现在与范围的关系 | Clear 调整 |
     | --- | --- |
     | 现在在范围内（含端点） | 两端均保留 |
     | 范围全在未来：现在 < 开始 | 仅开始改为现在前 1 个月，结束不变 |
     | 范围全在过去：现在 > 结束 | 仅结束改为现在后 1 年，开始不变 |

   - “月/年”按 UTC 日历加减，保留时分秒，月末/闰日夹到目标月合法末日；不是固定30/365天。
   - 不因 Clear 把另一端重置为默认 ±10 年，不把现在夹回原范围端点。
   - 项目边界行为：播放到右端时暂停，不自动修改用户边界。
   - 场景模拟时钟与任务计算/详情快照分开；拖动不会悄悄重算旧任务。
   - 地球/月球自转公转和太阳照明由模拟时刻驱动；有地球/月球视角切换。使用真实天体尺寸；远距渲染处理不可混入物理模型。

   - siteSky 返回太阳/地球的圆盘中心高度角、方位角、视半径、距离；现有 isUp 为 elevation + angularRadius > 0，表示任意圆盘部分高于平坦地平线。
   - siteTimeline 包括 findEvents、upIntervals、summarize、statusAt，可提供窗口、比例和最长可见/不可见；还没有 UI 接入。
   - 当前零海拔、球形月面、平坦地平线，不含地形遮挡、地面站、最低仰角遮罩或链路预算。
